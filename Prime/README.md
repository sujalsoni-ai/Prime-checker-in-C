## 📌 About the Project

The **Prime Number Checker** is a beginner-friendly project written in the C programming language. It checks whether a number entered by the user is prime using a `while` loop and conditional statements.

This project helps beginners practice basic C programming concepts and improve their problem-solving skills.

## ✨ Features

- ✅ Takes an integer as input from the user.
- 🔍 Checks whether the number is prime or not.
- 🔄 Uses a `while` loop to check divisibility.
- ⚡ Uses `break` to stop the loop when a divisor is found.
- 🛡️ Correctly handles numbers less than 2.

## 🛠️ Technologies Used

- **Language:** C
- **Compiler:** GCC (MinGW)
- **Code Editor:** Visual Studio Code

## ▶️ How to Run

**Step 1:** Clone this repository.

```bash
git clone https://github.com/YOUR-USERNAME/prime-number-checker.git
```

**Step 2:** Open the project folder in VS Code.

**Step 3:** Compile the program using GCC.

```bash
gcc prime.c -o prime
```

**Step 4:** Run the program on Windows.

```bash
.\prime.exe
```

## 📷 Sample Output

**Example 1: Prime Number**

